# 既知の問題と制約

最終確認日: 2026-09-08。修正したら行を消す（履歴は git に残る）。

## 制約（設計上、当面直さない）

| 項目 | 内容 | 回避策 |
|---|---|---|
| 通話向け音声処理と音楽 | 「通話向けの音声処理（実験的）」を有効にしても、音楽と他人の声を完全には分離できない。音楽再生中の適切な収録方法は調査中 | 再生音量を保ちたい場合はオフのまま使う（既定オフ） |
| Git管理外での`.gitignore`解釈 | Git 管理外のフォルダを検索対象にすると、`fd` がない環境では ignore 設定を反映せず全ファイルを索引する | `fd` をインストールする |
| ファイル検索プレビューの上限 | プレビューは検索対象内の通常ファイルに限り、最大 64 KiB・40 行まで | プレビューではなく実ファイルを開いて確認する |
| Bluetooth ヘッドセットのマイクと音楽の再生 | Bluetooth ヘッドセットのマイクを使うと macOS が通話用プロファイルに切り替え、音楽が途切れることがある。切り分け中（診断ログの `transport=` を参照） | 内蔵マイクなど Bluetooth 以外の入力を既定にする |
| HUD の編集位置が絵文字を割ることがある | 本文の編集位置は UTF-16 の位置で受け取るため、モデルと表示がずれた回に絵文字（サロゲートペア）の途中を指し、`�` が混ざりうる。通常の入力経路（テキストビューが渡す位置）では起きない | 混ざった文字を消して打ち直す |
