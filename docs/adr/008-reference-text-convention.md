# ADR-008: 正解テキストの表記規約

- 状態: **承認**
- 日付: 2026-09-01
- 関連: M0 コーパス記録（非公開）、ADR-007

## 文脈

疑似音声で CER を取ったところ、内訳が「三十秒」→「30秒」、句読点の付加、といった**表記の揺れ**で支配されていた。
規約を決めないと、モデルの実力ではなく表記ルールの差を CER として測ってしまう。
自作コーパス 100 文の録音前に潰す必要があった。

## 判断

| 項目 | 規約 |
|---|---|
| 数字 | 半角アラビア数字（「30秒」。「三十秒」とは書かない） |
| 文としての句読点 | 参照テキストと CER 計算の**双方から除外** |
| 技術識別子中の記号 | `.` `/` `_` `-` は保持（`RingBuffer.swift` の `.` は消さない） |
| フィラー・言い直し | 省略しない（「えっと」「あ、違う」を正解に含める） |

100 文をこの規約で揃え直した（対象句読点・漢数字ともに 0 件）。

## 理由

- 数字: Apple / Nemotron ともアラビア数字を出力する。漢数字を正解にすると実力と無関係に誤りが乗る
- 句読点: モデルごとに付与ポリシーが違い、比較を汚す。除外して文字認識の実力だけを見る
- 識別子の記号: vox の用途はコード識別子の混在した発話。ここを消すと肝心な部分が測れない
- フィラー: 実際の発話にあるものは正解に含めないと、モデルがフィラーを拾ったときに誤りとして数えてしまう

## 効果（疑似音声で確認）

| sample | 規約前 | 規約後 |
|---|---:|---:|
| smoke1 | 0.211 | 0.158 |
| smoke2 | 0.083 | **0** |
| smoke3 | 0.045 | **0** |

残る smoke1 の 0.158 は「リングバッファ」→「リングバファ」で、本物の認識誤り。表記の揺れを実力と誤認する問題は解消した。

## 見直しの条件

- フィラー除去を製品機能として入れるとき → 「フィラーを含む正解」と「除去後の正解」の両方を持つ
