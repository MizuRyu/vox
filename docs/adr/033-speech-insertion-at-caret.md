# ADR-033: 新しい音声をカーソル位置から挿入する

- 状態: 承認（2026-11-01の利用者からの修正依頼）
- 日付: 2026-11-01
- 関連: ADR-011の音声挿入位置を変更。録音・貼り付け先・手入力の扱いは同ADRに従う

確定済みの文の途中を手入力で直したあと、次の音声が末尾へ入るため、その場で文章を補えなかった。新しい認識区間はカーソル位置から始める。淡色が出たあとは位置を固定し、認識結果が伸び縮みしても別の場所へ移さない。カーソルを動かした場合は、その区間が確定してから始まる次の区間に反映する。

`head + tentative + tail`の3区画を維持し、挿入位置の後ろにある既存の文も`tail`に保持する。モデルがカーソルを持ち、ビューは共通の前後を残した差分置換で追従する。IME変換中の認識結果とパス挿入は保留し、変換した文字を反映してから順に適用する。

末尾への追加を続ける案は、途中の編集位置から話して補う使い方を満たさないため採らない。認識途中の淡色をカーソルの移動先へ移す案も、発話中の文章と手入力の順序が変わるため採らない。選択中の確定本文を音声で削除する操作は追加しない。

## 見直しの条件

認識区間の途中でカーソルを移したときにも、以後の音声をその位置へ切り替えたいという要望が出たら、認識区間を明示的に確定する操作を検討する。認識結果の更新ごとに位置を動かす設計には戻さない。
