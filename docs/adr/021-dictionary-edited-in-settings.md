# ADR-021: 辞書は設定画面の表で編集し、ファイルは正のまま残す

- 状態: **提案**（2026-09-24）
- 関連: [ADR-019](019-dictionary-surface-replacement.md)（辞書の形式と照合。本文は変えない）、[仕様 05](../specs/05-text-postprocessing.md)、[content-guidelines](../content-guidelines.md)

## 文脈

ADR-019 の初版は、辞書を `dictionary.tsv` に置き、設定画面には「辞書ファイルを開く」「更新」と読み込み結果だけを出した。
実機で使い始めた利用者の要望は「ファイルを開くのではなく、設定画面から普通に追加したい」（2026-09-24）。
タブ区切りをエディタで書く手順は、1 語直したいだけの場面には重い。

## 判断

**設定画面の「辞書」に表を置き、行の追加・編集・削除をそこで行う。保存先は今までどおり `dictionary.tsv` で、形式も変えない。**

- 表の列は「置き換える表記」「入れたい表記」の 2 列。行の追加は空の行を足して打ち込む。削除は行を選んで「削除」
- 編集はセルの確定（Enter またはフォーカスを外す）ごとにファイルへ書く。「保存」ボタンは置かない（設定画面の他の項目と同じ即時保存）
- **ファイルの中の、表に出ない行は書き換えない。** `#` のコメント、空行、壊れた行は元の位置にそのまま残し、
  表の行だけを元の行の位置で書き換える。新しい行は末尾に足す。削除は行ごと消す
  - 理由: 利用者がエディタで書いた説明や、直し途中の壊れた行を、設定画面の編集が黙って消さないため
- 左辺が空の行は保存しない（打ち込み途中の行として画面に残す）。左辺が既にある行と重複したら保存せず、
  「「<表記>」はすでにあります。」と知らせる
- 壊れた行の知らせ方は ADR-019 のまま（件数と行番号）。設定画面で直せるのは表に載る行だけで、壊れた行はエディタで直す
- 「辞書ファイルを開く」「更新」は残す。エディタでの一括編集と、外で書き換えた後の読み直しのため
- 反映のタイミングは変えない（録音開始時に読む）

## 影響

- 表の編集とファイルの直接編集の両方が成り立つ。ファイルが正なので、どちらで直しても同じ結果になる
- 行の位置を保つために、ファイルを「行の列」として持つ純粋なモデル（VoxCore）が増える。
  置換の照合（`DictionaryTable` / `DictionaryPass`）は変えない
- 設定画面が縦に伸びる。表の高さは行数に応じて上限つきで伸ばす

## 却下した案

- **表の保存でファイル全体を書き直す（コメントを捨てる）**: 実装は簡単だが、利用者が書いたコメントと壊れた行が消える。ADR-019 の「壊れた行は落として続ける」が「壊れた行は消える」に変わってしまう
- **辞書を `settings.json` に移す**: ADR-019 で却下済み。壊れた行を落として続けられない
- **表の編集中はファイルへの書き込みを溜めて「保存」で書く**: 設定画面の他の項目が即時保存なので、辞書だけ手順が増える

## 見直す条件

- 辞書が 100 行を超える使い方が出たとき（表の検索・並べ替えが要る）
- 訂正 UI（ADR-019 の却下案。語のクリックで辞書に追加）を入れるとき。表はその受け皿になる
