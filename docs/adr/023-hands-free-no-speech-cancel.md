# ADR-023: 声だけで始めた録音は、誰も話さなければ音を鳴らしてやめる

- 状態: **提案**（2026-09-25）
- 関連: [ADR-022](022-external-record-control-url.md)（ほかのアプリからの録音操作）、[ADR-020](020-pause-triggered-segment-commit.md)（無音の検出）

## 文脈

parley の会話モードは、読み上げが終わると `vox://record/start` で次の録音を自動で始める。利用者が席を離れたり話すことが無かったりすると、ADR-022 の録音は誰も話さないまま続き、マイクが開いたままになる。
画面を見ていない利用者には、録音が続いているのか終わったのかも分からない。

## 判断

**`start` / `toggle` に `cancel_if_no_speech_ms=<3000〜120000>` を足す。録音を始めてからこの時間、発話レベルを超えた音も手入力も無ければ、何も貼らずに録音をやめ（Esc と同じ破棄）、システムの効果音「Bottle」を 1 回鳴らす。**

- 判定は ADR-022 の無音での確定と同じ型 `HandsFreePolicy`（VoxCore、旧 `SilenceFinishPolicy`）にまとめ、「続ける / 確定する / やめる」を返す。どちらの規則も URL で指定した録音だけに効く
- 時間はマイクが実際に聞き始めた時から数える（マイクの許可待ちやモデルの準備は数えない）
- 一度でも話した、打った、日本語の変換を始めた録音は、この規則ではやめない。打った本文を全部消した後もやめない（打鍵・変換の開始・パレットからの差し込みを HUD が録音ごとに記録する。準備中の入力も数える）（話した後の沈黙は `finish_after_silence_ms` の役目）
- パレットを開いている間と、選んだパスを差し込み終えるまではやめない（差し込み待ちは件数で数え、開き直して Esc で閉じても消えない）
- 診断ログは `no_speech_cancel`。無音で確定した回は `silence_finish`
- 待つ時間の既定値は呼び出し側（parley は 20 秒）が持つ。考える時間が要るので、短い値は範囲で防ぐ

## 却下した案

- **録音キーで始めた録音にも効かせる**: 利用者が画面を見ながら考えている間に消える
- **音を鳴らさない**: 画面を見ていない使い方が前提なので、終わったことが分からない
- **音を parley が鳴らす**: parley は vox の録音が終わったことを知る手段を持たない（URL は一方向）

## 見直す条件

- 効果音が他のアプリの通知音と紛れる時（専用の音、または音を選べる指定）
- 周囲の雑音で「話した」と判定され、やめるべき時にやめない事例が出た時（テキストの有無も条件に入れる）
