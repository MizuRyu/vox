# ADR-028: 文字だけで疑問と言える文末の「。」を「？」にする

- 状態: **提案**（2026-10-18）
- 関連: [ADR-012](012-filler-removal-rule-based.md)（規則ベースの後処理）、[ADR-019](019-dictionary-surface-replacement.md)、[05 テキスト後処理](../specs/05-text-postprocessing.md)

## 文脈

利用者の訴え（2026-10-18）は「問いかけたのに『？』にならず、普通の文になる」。
履歴 638 件（4,816 文）を数えると、疑問形の文末で終わる文 375 文がすべて「。」で閉じていた（かな 202、ですかね 65、ですか 30、っけ 14 ほか）。
Apple `SpeechTranscriber` は同じ「〜ですか」にも「？」を付けたり付けなかったりする。vox の後処理には文末記号を見る段が無かった。

外部の調査（ChatGPT、2026-10-18。出典は未確認のまま `z-ai/` に保存）では、次の 2 点が挙がった。

- 「かな」は上げても下げても相手への問いかけになりうる。下げ調子＝独り言とは決められない
- 自然会話の「〜の」型の疑問の約 3 割は上がらない

どちらも、文字だけで「？」にしてよい文末は限られることを示す。

## 判断

1. **次の形で終わる文の「。」を「？」にする**
   - 丁寧語の疑問（です・ます・でした・ました・ません・でしょう ＋ か、後ろに「ね」が付く形を含む）と、そのくだけた形（いいっすか、ないすかね）
   - 思い出しの「っけ」
   - 同意を求める「よくね」「なくね」「方が良くない」と、頼みの「てくれん」
2. 「かな」「の」「のか」「ないか」は変えない。語尾の上げ下げを見る判定（別の ADR で扱う）に回す
3. 適用位置は確定差分の最後（辞書 → フィラー除去 → 疑問符）。フィラーを消した後の文末を見る。`tentative` と履歴の `raw_text` には掛けない
4. 設定項目は作らない。対象を誤りようのない形に絞ったので、切る理由が無い

履歴に当てると 145 文が「？」になる（ですかね 79、ですか 36、っけ 14、ますかね 8、ますか 5、ませんか 3）。
くだけた形・同意・頼みの形で、さらに 41 文が「？」になる（よくね・良くね 13、なくね 11、てくれん 5、っすか・いすか 9、方が良くない 3）。

くだけた形・同意・頼みの形は、vox の録音 273 文に文の意味から「？」を付けたいかのラベルを付けて（本人のラベルとは 6 文中 6 文が一致）、
文字の規則で拾えない「？」17 文を語尾ごとに履歴全体で数えて足した。語尾の上げ下げは、普段の話し方では
文末の F0 が 4〜6 割の文で取れず、拾えない「？」を足す適合率が 15% 前後に留まった（`benchmarks/prosody` の評価）。
「良くない」単独（「これは良くない。」）と「くれんかった」は平叙なので含めない。

## 却下した案

- **「か」で終わる文をすべて「？」にする**: 「やってみようじゃないか」「そうなのか」のような詠嘆・独白を壊す
- **「かな」も「？」にする**: 履歴で最多（202 文）だが、「帰ろうかな」のような独り言が混ざる。語尾の上げ下げで分ける方が筋が良い
- **LLM で文末を整える**: [ADR-012](012-filler-removal-rule-based.md) と同じ理由（遅延と、挿入する本文を予測できなくなること）

## 見直しの条件

- 上の形で「？」を付けたのに利用者が「。」に戻した事例が出たとき（その形を外す）
- 語尾の上げ下げによる判定を本体に入れたとき（この規則との優先順位を決め直す）
