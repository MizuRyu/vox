# ADR-029: 韻律の試作ツールはリポジトリに置き、声・ラベル・学習した重みは置かない

- 状態: **提案**（2026-10-18）
- 関連: [ADR-026](026-debug-recording-save.md)（録音の保存）、[ADR-028](028-question-mark-text-rule.md)（文字だけの疑問符）、[05 テキスト後処理](../specs/05-text-postprocessing.md)

## 文脈

「かな」「の」で終わる文は、文字だけでは問いかけか独り言かを決められない（ADR-028）。語尾の上げ下げで判定する試作を始めた。
試作は、録音とラベル付けの画面、F0 と文末の特徴、小さな分類器の学習・評価からなる。

学習に使うのは利用者本人の声と、本人が付けたラベル（どの文を問いかけとして書きたいか、正しい文）である。
学習した重みは、その人の話し方の癖を数値にしたものになる。vox のリポジトリは公開している。

## 判断

1. **ツールのコードは `benchmarks/prosody/` に置いて公開する。** 本体とは別に動く比較・測定の仕組みという点で `benchmarks/` と同じ性格。本体の `Package.swift` には触れない
2. **声・ラベル・学習した重み・評価の結果は `~/Library/Application Support/vox/prosody/`（0700）に置く。** vox の保存録音（`recordings/`）の隣。置き場は `VOX_PROSODY_DATA` で替えられる
3. `.gitignore` に `benchmarks/prosody/data/` と `.venv/` を入れる。置き場を中に向けても入らないようにする
4. 検査は合成の音（倍音つきの上昇・下降）だけで行う。実際の発話は fixture にしない（AGENTS.md の原則）
5. 本体へ移す判断（YIN と重みを Swift に持つか）は、自然な発話で評価してから別の ADR で行う。移すときも、重みは利用者の端末で学習・保存し、配布物には入れない

## 却下した案

- **プライベートリポジトリに分ける**: 利用者の判断（2026-10-18）で不要。コードは公開してよく、隠したいのはデータと重みだけ
- **ワークスペースに置いたままにする**: vox の録音形式（ADR-026 の JSON）と一緒に変わるコードが、vox の外で取り残される
- **学習した既定の重みを同梱する**: 1 人の話し方に合わせた重みで、他の人には当たらない。本人の声の癖も配ることになる

## 見直しの条件

- 本体に韻律の判定を入れると決めたとき（重みの保存先と学習の手順を本体側で決め直す）
- 他の人のデータで学習した重みを配る必要が出たとき
