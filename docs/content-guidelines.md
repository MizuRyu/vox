# コンテンツガイドライン（UI 文言の規約）

対象はアプリ内の文言（設定画面、セットアップ画面、HUD、パレット、メニューバー、通知、エラー）。README や docs は対象外（そちらは技術文書の表記に従う）。

## トーン

- 本文・説明・エラー・通知: です・ます調。敬語は「ください」「します」まで。「させていただく」「ございます」は使わない
- ボタン・ラベル・見出し・メニュー項目: 名詞形か動詞の終止形。句点なし
- 演出（達成、励まし）: 使わない。vox に演出の文言は置かない
- 権限・プライバシー・削除・送信: 平叙のです・ます。条件（保存されない、送信される、実行される）は削らない

## ボタンの形

- 名詞形（「保存」「閉じる」「更新」）。OS 標準の語は言い換えない
- 破壊的操作は対象が分かる語（「Vox を終了」→「Voxを終了」、「破棄」）
- 「キャンセル」は処理の中止、「閉じる」は表示を消すだけ。混用しない

## 句点

- 文（本文、説明、エラー、確認）には付ける
- ボタン、ラベル、見出し、メニュー項目、HUD の状態表示（「録音中」「確定中」）、通知の 1 行には付けない
- 通知は 1 文なら句点なし、2 文になるなら 1 文目にだけ付ける

## 表記

- 英数字と日本語の間: **スペースなし**（「Voxを終了」「Enterを押す」「F1〜F12は」）。macOS の日本語 UI に合わせる
- 記号入りのキー名（⌘⇧Space、⌃P）は前後にスペースなし。修飾キー同士は「・」で区切る（「⌘・⌃・⌥」）
- 長音: macOS の日本語 UI に従う（「サーバー」「ユーザー」「フォルダ」「メニューバー」）
- 開く語: こと、とき、ため、ください、できる、ない
- 記号: 「！」「？」は使わない。「…」は 1 つ（メニューの「設定…」は macOS 慣例）。括弧は全角「（）」。区切りは「・」
## 数量の形

- 「数値 + 単位」でスペースなし（「0.5秒」「3つ」「64KiB」「0/3」）

## 用語集

| 概念 | 採用語 | 不採用語 | 理由 |
|---|---|---|---|
| 録音キーを 2 度目に押して本文を送る操作 | 確定 | 送信、完了 | 「送信」は Enter による送信と紛れる |
| 確定した本文を元のアプリに入れる操作 | 貼り付け | 挿入、入力 | 利用者が見る動作は ⌘V の貼り付け。HUD の内部語「挿入」は UI に出さない |
| 確定後に Enter キーを送ること | Enterを押す | Enter を送る、自動 Enter | 利用者の視点では「押す」。設定名と通知で統一 |
| 貼り付けた本文を入力欄から読み返して照合すること | 入力内容を確認 | 読み返し、readback | 内部語を出さない |
| 入力欄を読み返せないアプリの代表 | ターミナル | 互換方式、afterPaste | 利用者が知っているのはアプリの種類 |
| ⌃P / @ で開く検索画面 | ファイル検索 | パレット、コマンドパレット | 「パレット」は内部語 |
| 音声入力の対象になる元のアプリ | 貼り付け先 | 挿入先、録音先、対象アプリ | 貼り付けと語を揃える |
| マイク・アクセシビリティ・入力監視の許可 | 権限 | 許可、アクセス | セットアップ画面と揃える |
| 権限を与える操作 | 許可する | 有効にする、オンにする | システム設定の語 |
| Apple のエコー除去・ノイズ抑制 | 通話向けの音声処理 | 音声処理、ボイスプロセッシング | 既存の設定名 |
| ログイン時に自動で起動する項目 | ログイン時に開く | ログイン項目、自動起動 | システム設定の語 |

## 決めた理由

- スペースなしを採ったのは、macOS の日本語 UI（システム設定、Finder）が「Finderを終了」のように詰めており、設定画面が OS のダイアログと並ぶため。docs と README は技術文書の慣習（スペースあり）のままにし、境界は「アプリの画面に出るか」で引く
- 「Enterを押す」に統一したのは、旧文言が「Enter を押す」「Enter を送る」「自動 Enter」の 3 通りだったため
- 「貼り付け先」に統一したのは、旧文言が「挿入先」「録音先」「対象アプリ」の 3 通りだったため
