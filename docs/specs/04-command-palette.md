# 04 コマンドパレット

録音を止めずに開くパレット、sigil によるソース切替、検索対象フォルダの解決。

最終確認日: 2026-09-07

音声供給の一時停止は廃止しました。パレットを開くときは未確定部分の確定処理だけを別タスクで行い、
モデル・セッション・音声供給を維持します。パレット表示中の発話も通常どおり本文に反映します。

## sigil によるソース切替

パレットは「ファイル選択 UI」ではなく **発話中のコマンドパレット**として設計します（[ADR-005](../adr/005-command-palette-sigil.md)）。
単一ホットキー `⌃P`（変更可）で開き、先頭の記号でソースを切り替えます。HUD に `@` を打つ方法もあります。

| sigil | ソース | v1 |
|---|---|---|
| `@` | リポジトリ内のファイルパス | **実装する** |
| `#` | シンボル / 関数名 / クラス名 | 拡張 |
| `!` | 定型コマンド・スニペット | 拡張 |
| `~` | git ブランチ名 | 拡張 |
| `%` | クリップボード履歴 | 拡張 |

**v1 で実装するのは `@` だけです。** ただし**ソースを差し替え可能なインターフェースとして最初から作ります**。
理由は、後から足すのが難しいのは実装ではなく**指が覚えた操作**だからです。
sigil 方式なら、ソースを何個足してもホットキーが増えず、筋肉記憶も壊れません。

sigil の割り当てを設定画面で変更する機能は未実装です。
`~` をフォルダ選択モードにも使う案があるため、既存のブランチ用 sigil との適用範囲は実装時に整合させます。

## 流れ

1. **`⌃P` または `@`** — パレットを開き、`SpeechLane.finalizeSegment()` を別タスクで実行する。音声供給は止めない。
2. **対象の解決** — 録音開始時の前面アプリをもとに検索対象を解決する。取得できなければ `--repo` を使う（下記）。
3. **検索とプレビュー** — 左に候補、右にプレビューを表示する。クエリが空なら変更ファイルを優先し、入力があれば fuzzy match で絞る。プレビューは選択・コピーでき、ヘッダのボタンで表示中のプレビューテキストをまとめてコピーできる。
4. **`Enter`** — 開いた時点の確定処理を待ち、本文末尾にパスを挿入する。`@` を `head` の途中に打った場合だけ、その位置に挿入する。
5. **閉じる** — HUD にキーフォーカスを戻す。`esc` はパスを挿入しない。音声供給の再開処理は不要で、状態表示は「録音中」のまま。

## 検索対象の解決

検索対象は「トグル ON 時の前面アプリ」から導きます（R15、[ADR-011](../adr/011-hud-edit-mode-and-context-cwd.md)）。

- **Orca が前面のとき** — Orca の画面でアクティブなローカル worktree を検索対象にする。
- **ターミナルが前面のとき** — その cwd を含むリポジトリを検索対象にする。
- **一意に決まらないとき** — `--repo` で指定した検索フォルダを使う。

### 同一リポジトリの別 worktree

現在の検索対象が Git worktree の場合、同じリポジトリにある別の worktree を自動で調べます。
候補はクエリが空の Changes 表示でファイル行の前に並び、`worktree` バッジが付きます。
候補を選ぶとパスを挿入せず、その worktree に検索対象を切り替えて索引を読み直します。
検索中と Tree 表示には候補を出しません。

## 索引とプレビュー

パレットを開くたびに `FileIndexer.load` で索引を作ります。Git のファイル一覧と変更状態を読み、`.gitignore` を尊重します。
追跡済みのファイルは、後から ignore 対象にしても索引に残ります。Git 管理外では `fd` があれば ignore 設定を反映しますが、
`fd` がない場合の代替処理は `.gitignore` を解釈しません。`FSEvents` による差分更新は将来案です。
検索対象として任意のフォルダを選ぶ機能は未実装です。

プレビューは検索対象内の通常ファイルに限り、最大 64 KiB・40 行です。検索対象外のファイル、シンボリックリンク、
特殊ファイルの本文は開きません。パスの挿入はファイル内容の送信ではありません。

計測は schema 5 の `palette_open_ms`（表示していた時間）を使い、旧 `palette_resume_ms` は廃止しました。
